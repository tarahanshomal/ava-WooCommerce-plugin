# پیامک آوا برای ووکامرس

افزونهٔ مستقل **ava-WooCommerce-plugin** برای ارسال پیامک‌های سفارش ووکامرس از طریق سرویس آوا، توسعه‌یافته توسط [طراحان شمال](https://github.com/tarahanshomal).

- پیامک وضعیت سفارش برای مشتری، با متن جداگانه و قابل ویرایش برای هر وضعیت.
- اطلاع‌رسانی سفارش جدید و وضعیت‌های منتخب به شماره‌های مدیر فروشگاه.
- ارسال دستی از صفحهٔ سفارش و ارسال آزمایشی با تأیید مدیر.
- صف ارسال در پس‌زمینه، جلوگیری از ثبت تکراری اعلان خودکار و گزارش وضعیت پیامک.
- تنظیمات فارسی، پشتیبانی از شماره‌های ایرانی و ارقام فارسی/عربی.
- استفاده از API سفارش ووکامرس برای سازگاری با HPOS و پشتیبانی از تسویه‌حساب کلاسیک و بلوکی.

## نصب

1. از [Releases](https://github.com/tarahanshomal/ava-WooCommerce-plugin/releases) فایل **ava-WooCommerce-plugin-1.0.0.zip** را دریافت کنید. فایل ZIP پیوست انتشار برای نصب آماده است؛ فایل خودکار «Source code» بستهٔ افزونه نیست.
2. در وردپرس به **افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه** بروید و ZIP را نصب و فعال کنید.
3. در **ووکامرس ← پیامک آوا** تنظیمات اتصال و متن پیام‌ها را وارد کنید.

نیازمندی‌ها: PHP 7.4 یا جدیدتر، وردپرس 6.5 یا جدیدتر، ووکامرس 8.2 یا جدیدتر و دسترسی HTTPS از فروشگاه به پنل آوا.

## راه‌اندازی اتصال

در پنل آوا یک کلید API با دسترسی‌های **`sms:send`** و **`sms:read`** بسازید. نشانی پیش‌فرض پنل **`https://ava.tarpardaz.com`** است؛ برای پنل اختصاصی، نشانی HTTPS همان پنل را وارد کنید. شمارهٔ فرستنده را فقط اگر برای حسابتان فعال است تنظیم کنید؛ خالی گذاشتن آن، انتخاب فرستنده را به آوا می‌سپارد.

شماره‌های مدیر را وارد کنید، وضعیت‌های مورد نظر و متن پیام‌ها را انتخاب کنید و ارسال خودکار را فعال کنید. ارسال خودکار پس از نصب غیرفعال است. برای بررسی اتصال از فرم ارسال آزمایشی استفاده کنید؛ این فرم پیامک واقعی و هزینه‌دار ارسال می‌کند و تأیید آن الزامی است. افزونه موجودی ساختگی یا تأیید اتصال بدون ارسال نمایش نمی‌دهد.

کلید ذخیره‌شده در فرم بازنمایی نمی‌شود. برای حفظ کلید قبلی، فیلد کلید را خالی بگذارید؛ برای تعویض، کلید جدید را وارد کنید. کلید را در مخزن Git، گزارش خطا یا تصویر تنظیمات منتشر نکنید. در صورت تمایل، به‌جای ذخیرهٔ کلید از طریق فرم، آن را در `wp-config.php` و پیش از خط پایان تنظیمات تعریف کنید:

```php
define( 'AVA_WOO_API_KEY', 'YOUR_AVA_API_KEY' );
```

مقدار نمونه را با کلید واقعی خود جایگزین کنید. وقتی این ثابت تعریف شده باشد، فیلد کلید در افزونه غیرفعال می‌شود و مقدار ثابت در تنظیمات پایگاه داده کپی نمی‌شود.

اعلان «سفارش تازه» برای سفارش‌های ثبت‌شده از تسویه‌حساب کلاسیک یا بلوکی ارسال می‌شود. سفارش‌های ساخته‌شده در مدیریت یا REST API، در صورت انتخاب وضعیت مربوط، اعلان تغییر وضعیت دریافت می‌کنند. قالب مدیر برای اعلان سفارش تازه و وضعیت‌های منتخب مدیر مشترک است؛ متن آن را با توجه به این کاربرد تنظیم کنید.

## متغیرهای متن پیام

| متغیر | مقدار |
| --- | --- |
| `{order_id}` | شناسهٔ داخلی سفارش |
| `{order_number}` | شمارهٔ نمایشی سفارش |
| `{order_status}` | عنوان وضعیت سفارش |
| `{order_total}` | مبلغ سفارش به صورت متن |
| `{currency}` | ارز سفارش |
| `{billing_first_name}` | نام مشتری |
| `{billing_last_name}` | نام خانوادگی مشتری |
| `{billing_phone}` | شمارهٔ ثبت‌شدهٔ مشتری |
| `{payment_method}` | عنوان روش پرداخت |
| `{shipping_method}` | عنوان روش ارسال |
| `{site_name}` | نام فروشگاه |

نمونه:

```text
{billing_first_name} عزیز، سفارش {order_number} شما در {site_name} به وضعیت «{order_status}» تغییر کرد.
مبلغ سفارش: {order_total} {currency}
```

متن نهایی پیام باید بین ۱ تا ۱۰۰۰ نویسه باشد. متن‌های بلند ممکن است به چند بخش پیامک تقسیم شوند؛ هزینه و پذیرش نهایی را آوا تعیین می‌کند. افزونه اعلان‌ها را با پیامک متنی ارسال می‌کند. API الگوی OTP آوا مخصوص رمز یک‌بارمصرف است و برای پیام وضعیت سفارش استفاده نمی‌شود.

## صف و گزارش ارسال

ارسال از فرایند تسویه‌حساب جداست و در پس‌زمینه انجام می‌شود. صف از Action Scheduler ووکامرس و در نبود آن از WP-Cron استفاده می‌کند. در فروشگاه‌های کم‌ترافیک، اجرای منظم cron وردپرس را در هاست تنظیم کنید.

**ثبت در صف، پذیرش توسط سرویس و تحویل به گوشی سه وضعیت متفاوت‌اند.** پاسخ ۲۰۲ آوا فقط ثبت درخواست در صف را تأیید می‌کند. در گزارش‌ها، وضعیت ثبت‌شدهٔ آوا را بررسی و در صورت نیاز گزارش را به‌روزرسانی کنید. اگر ارتباط هنگام ارسال قطع شود و نتیجه مشخص نباشد، افزونه پیام را خودکار دوباره ارسال نمی‌کند تا احتمال پیامک و هزینهٔ تکراری کاهش یابد.

اگر پس از ثبت پیام در صف، دامنهٔ پنل، کلید API یا خط فرستنده را عوض کنید، پیام‌های قبلی صف لغو می‌شوند تا از ارسال با حساب یا خط دیگری جلوگیری شود. گزارش پیام‌های قبلی نیز فقط با اتصال همان حساب قابل دریافت است.

اعلان خودکار یک سفارش برای همان وضعیت، گیرنده و مخاطب دوباره ثبت نمی‌شود. بازگرداندن سفارش به همان وضعیت، پیام تازه ایجاد نمی‌کند؛ برای ارسال مجدد آگاهانه، از ارسال دستی سفارش استفاده کنید. هر بار بازکردن فرم و ارسال دستی یا آزمایشی یک درخواست جدید است؛ تکرار ارسال همان فرم، درخواست تکراری ایجاد نمی‌کند.

## حریم خصوصی و سرویس بیرونی

افزونه برای ارسال، شمارهٔ گیرنده، متن پیام، فرستندهٔ انتخابی و کلید احراز هویت را از طریق HTTPS به پنل آوای تنظیم‌شده ارسال می‌کند. اگر در متن از متغیرهای سفارش استفاده کنید، همان اطلاعات سفارش نیز در متن ارسالی قرار می‌گیرد. برای جزئیات سرویس و سیاست داده‌های آوا به [پنل آوا](https://ava.tarpardaz.com) مراجعه کنید.

گزارش محلی شامل شماره، متن پیام و وضعیت ارسال در پایگاه دادهٔ وردپرس نگهداری می‌شود. شماره‌ها در فهرست گزارش به صورت پوشیده نمایش داده می‌شوند، اما دادهٔ اصلی در پایگاه داده باقی می‌ماند. دورهٔ نگهداری پیش‌فرض ۳۰ روز است و از تنظیمات قابل تغییر است. دسترسی به تنظیمات، ارسال دستی و گزارش‌ها به مدیرانی با مجوز `manage_woocommerce` محدود می‌شود. بکاپ پایگاه داده و دسترسی افزونه‌های دیگر نیز باید مطابق سیاست فروشگاه مدیریت شود.

## توسعه و ساخت بسته

```sh
php tests/run.php
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 scripts/package.py
```

برای آزمون صف، افزونهٔ PHP `pdo_sqlite` نیز لازم است؛ نصب معمول افزونه به SQLite وابسته نیست. بسته در پوشهٔ `build/` همراه فایل SHA256 ساخته می‌شود. ساخت تکراری از فایل‌های یکسان خروجی یکسان می‌دهد. آزمون‌ها از دادهٔ نمونه و HTTP شبیه‌سازی‌شده استفاده می‌کنند و به مشتری واقعی پیام نمی‌فرستند. گردش CI نحو PHP و آزمون‌ها را روی نسخه‌های PHP 7.4، 8.2 و 8.4 اجرا می‌کند.

### اعتبارسنجی نسخهٔ ۱٫۰٫۰

آزمون یکپارچه در یک نصب محلی و موقت با وردپرس **7.1.4**، ووکامرس **11.2.1**، PHP **8.5.4** و MariaDB **11.8.6** انجام شد. ایجاد سفارش، رویدادهای تسویه‌حساب، اعلان‌های وضعیت، صف و گزارش ارسال، و دسترسی مدیر در هر دو حالت ذخیره‌سازی کلاسیک سفارش و **HPOS** بررسی شدند. ارتباط پیامکی در این آزمون‌ها شبیه‌سازی شد و پیامک واقعی ارسال نشد.

مجموعهٔ مستقل نیز **۱۸۵ بررسی رفتاری PHP** و **۳ آزمون بسته‌بندی** را گذراند؛ از جمله شماره‌های فارسی، قالب‌ها، احراز هویت، جلوگیری از ارسال تکراری، نتیجهٔ نامشخص ارسال، تغییر حساب آوا و الزامات امنیتی فرم‌های مدیریت. این نتیجه مربوط به نسخه‌های نام‌برده است؛ سازگاری با افزونه‌ها و قالب‌های دیگر باید در محیط آزمایشی فروشگاه بررسی شود.

برای انتشار نسخهٔ جدید، شمارهٔ نسخهٔ افزونه و `readme.txt` را هماهنگ کنید، آزمون‌ها را اجرا کنید و تگ `vX.Y.Z` را ارسال کنید. گردش انتشار، ZIP قابل نصب و checksum را در GitHub Releases قرار می‌دهد. افزونه به‌روزرسان خودکار اختصاصی یا انتشار خودکار در WordPress.org ندارد.

## English

Ava SMS notifications for WooCommerce by Tarahan Shomal. Configure customer status messages, administrator notifications, reusable placeholders, manual order messages and an explicit paid test. The plugin uses Ava's public Bearer-token SMS API, asynchronous processing, idempotency keys, permission checks and HPOS-compatible WooCommerce order APIs. Install the release ZIP, open **WooCommerce → Ava SMS**, enter your panel URL and a key with `sms:send` / `sms:read`, then enable automatic notifications. Persian is the primary interface language. Queued messages are not proof of delivery; uncertain sends are never automatically retried.
