# Security

Security fixes are provided for the latest published version. Keep WordPress, WooCommerce and this plugin updated.

For a suspected vulnerability, use the repository's private **Security → Report a vulnerability** option when available. If it is unavailable, ask the maintainer for a private reporting channel without posting exploit details or credentials publicly. Do not put API keys, complete phone numbers or customer message contents in issues or pull requests.

If a key is exposed, revoke it in Ava, create a replacement with only the required `sms:send` and `sms:read` scopes, and update the plugin settings. Restrict access to the WordPress database and backups because API credentials and local message logs are stored there.
